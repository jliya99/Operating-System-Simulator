About The Project

A practical Operating System project developed using Python and Tkinter.

The Operating System Simulator demonstrates important Operating System concepts through an interactive graphical user interface.

The application contains five major modules: Process Management, CPU Scheduling, Memory Management, File Management, and Deadlock Management.

The project implements algorithms including FCFS, SJF, Round Robin, FIFO, LRU, Paging, and Banker's Algorithm.

Module Details

Quick overview of the functionality implemented in each module.

⚙️ Process Management

This module manages processes inside the Operating System Simulator.

  • Create new processes.
  • Store Process ID, Name, Arrival Time, Burst Time and Priority.
  • Display process queue.
  • Terminate selected processes.

🖥️ CPU Scheduling

This module demonstrates CPU scheduling algorithms.

  • First Come First Serve (FCFS).
  • Shortest Job First (SJF).
  • Round Robin scheduling.
  • Completion Time.
  • Waiting Time.
  • Turnaround Time.
  • Gantt Chart.

💾 Memory Management

This module demonstrates paging and page replacement.

  • Page allocation.
  • Page table.
  • FIFO page replacement.
  • LRU page replacement.
  • Page faults and page hits.

📁 File Management

This module provides basic file management operations.

  • Create text files.
  • Delete files.
  • Read file content.
  • Write file content.
  • Refresh file list.

🔐 Deadlock Management

This module implements Banker's Algorithm for safe-state detection.

  • Maximum resource matrix.
  • Allocation matrix.
  • Available resources.
  • Need matrix.
  • Safe state detection.
  • Safe sequence generation.

How To Run The Simulator

The website is a project showcase. The actual simulator runs as a Python desktop application.

1. Clone the Repository

git clone https://github.com/jliya99/Operating-System-Simulator.git

2. Open Project Folder

cd Operating-System-Simulator

3. Run The Application

python main.py

4. Explore The Simulator

The Operating System Simulator dashboard will open. Select any module and test the implemented Operating System concepts.
