About The Project

A practical Operating System simulation project developed using Python and Tkinter.

The Operating System Simulator is designed to demonstrate important concepts of Operating Systems in an interactive and easy-to-understand way.

The application contains modules for Process Management, CPU Scheduling, Memory Management, File Management, and Deadlock Management.

It implements well-known algorithms such as FCFS, SJF, Round Robin, FIFO, LRU, Paging, and Banker's Algorithm.

Project Modules

Five major Operating System modules are included in the simulator.

⚙️

Process Management

Manage processes and demonstrate basic process operations.

  • Create Process
  • Terminate Process
  • Process Queue
  • Process Status
🖥️

CPU Scheduling

Simulate different CPU scheduling algorithms.

  • FCFS
  • SJF
  • Round Robin
  • Gantt Chart
💾

Memory Management

Demonstrate paging and page replacement techniques.

  • Paging
  • Page Table
  • FIFO
  • LRU
📁

File Management

Manage text files using the file management module.

  • Create File
  • Delete File
  • Read File
  • Write File
🔐

Deadlock Management

Detect safe and unsafe states using Banker's Algorithm.

  • Maximum Matrix
  • Allocation Matrix
  • Need Matrix
  • Safe Sequence

How To Run

Follow these simple steps to run the desktop application.

1. Clone the Repository

git clone https://github.com/jliya99/Operating-System-Simulator.git

2. Open the Project Folder

cd Operating-System-Simulator

3. Run the Application

python main.py

4. Explore the Simulator

The Operating System Simulator dashboard will open. Select any module to explore its functionality.
